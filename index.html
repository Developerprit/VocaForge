Singing voice, framed.把歌声，框进代码。 A console-free library to synthesize AI vocals — and a CLI that lets agents drive it.一个无控制台的声库框架，外加让 Agent 驱动的命令行。

VocaForge wraps DiffSinger behind a pluggable backend: real inference where GPUs live, a runnable stub everywhere else. List, resolve (404 / 103), and synthesize from any Python process or AI agent. VocaForge 用可插拔后端封装 DiffSinger：有 GPU 处接真实推理，无模型处也能跑。无论是 Python 进程还是 AI Agent，都能列声库、解析（404 / 103）、合成歌声。

Architecture架构

One engine, pluggable backends.一个引擎，可插拔后端。

An agent or CLI speaks JSON. The engine resolves a model against the local registry, picks the right backend, and returns raw WAV bytes. Agent 或 CLI 用 JSON 对话。引擎对照本地注册表解析声库、挑选后端，返回原始 WAV 字节。

vf-cli

Five commands. English output.五个命令，英文输出。

$ vf-cli info # version + backend availability $ vf-cli models # list registered voice libraries $ vf-cli synth --model stub-zh \ --lyrics "你好世界" --out hello.wav $ vf-cli export --project proj.json \ --model stub-zh --out out.wav $ vf-cli serve --host 127.0.0.1 --port 8765

Agent RPCAgent 接口

POST /vf, read the code.POST /vf，读 code 字段。

HTTP 103 is informational and cannot be a terminal status, so 103 is surfaced inside the JSON envelope. Agents read code, not just the HTTP status. HTTP 103 是 1xx 信息码、不能作为终态，因此 103 放在 JSON 信封内。Agent 读 code 字段，而非仅看 HTTP 状态。

HTTPcodeMeaning含义
404404model not found in the registry注册表中找不到该声库
200103model found and loaded找到并加载
200200success (e.g. synthesis complete)成功（如合成完成）
# resolve a model curl -s -X POST localhost:8765/vf \ -d '{"action":"resolve","model":{"id":"stub-zh"}}' # -> {"code":103,"message":"model found and loaded", ...} # synthesize curl -s -X POST localhost:8765/vf \ -d '{"action":"synth","model":{"id":"stub-zh"},"lyrics":"测试","out":"rpc.wav"}' # -> {"code":200,"message":"synthesis complete", ...}

Quick start快速开始

Two lines to a WAV.两行出一首 WAV。

# as a library from vocaforge import VocaForgeEngine from vocaforge.synth.project import Note, SynthProject engine = VocaForgeEngine() project = SynthProject(notes=[Note("do", 60, 0.4), Note("mi", 64, 0.4)]) audio = engine.synthesize("stub-zh", project) open("out.wav", "wb").write(audio)
# or just run it (no install needed) python vf_cli.py synth --model stub-zh --lyrics "你好世界" --out hello.wav # build vf-cli.exe on a machine with a C compiler pip install nuitka python build_vf_cli.py # -> dist/vf-cli.exe
